### 🚀 Featured Open-Source Projects

- **[FSystem88/OpenVPN-WebUI](https://github.com/FSystem88/openvpn-webui)** — A custom-developed web interface for convenient administration of OpenVPN servers.
- **[FSystem88/WireGuardTunnel](https://github.com/FSystem88/WireGuardTunnel)** — A modern Windows GUI client for WireGuard, featuring split tunneling support, a system tray icon, and the `sing-box` core (built with C# / WPF).
- **[FSystem88/AntiDDoS](https://github.com/FSystem88/antiDDoS)** — A lightweight PHP script for protecting websites against DDoS attacks and brute-force attempts, featuring request rate limiting and automatic IP banning via `.htaccess` (⭐ 31).
- **[FSystem88/Moy-Nalog](https://github.com/FSystem88/moy-nalog)** — PHP API for integration and interaction with the official "My Tax" (Moy Nalog) service (LKNPD).
- **Anime Streaming & Telegram Bots** — Self-deploying backends for content streaming and downloading, integrated with Telegram bots.
